# Станіслав Грачов
### Junior Information Security Specialist · SOC Trainee · IT Support

📍 Яготин, Київська область, Україна · Відкритий до віддалених пропозицій

## Про мене

Початківець у сфері інформаційної безпеки з навчальною підготовкою з кібербезпеки та практичним досвідом налаштування комп'ютерів, операційних систем, мережевого обладнання й тестування програмного забезпечення.

Цікавлюся моніторингом подій безпеки, аналізом інцидентів, захистом Windows/Linux-систем і мереж. Шукаю першу позицію **Junior Information Security Specialist / SOC Trainee / IT Support**, де зможу застосовувати наявні знання та розвиватися під керівництвом команди.

## Технічні напрями

| Напрям | Знання та практика |
| --- | --- |
| **Операційні системи** | Windows: встановлення, драйвери, діагностика, облікові записи та права доступу; базове знайомство з Linux |
| **Мережі** | TCP/IP, DNS, DHCP, маршрутизатори, Wi-Fi, базова діагностика з'єднань |
| **Інформаційна безпека** | Основи контролю доступу (ACL, DAC, MAC, RBAC), принцип найменших привілеїв, журнали подій Windows, основи реагування на інциденти |
| **Стандарти** | Навчальне ознайомлення з ISO/IEC 27001, 27002, 27005 |
| **Інструменти та розробка** | Git/GitHub, базове налаштування Node.js і PostgreSQL, тестування вебфункцій, робота з AI-асистентами |
| **Технічна підтримка** | Діагностика проблем ОС, драйверів, мережевого підключення та периферії |

> Рівень знань у різних темах відрізняється: частина навичок отримана в навчальних лабораторних роботах, частина — у власних практичних завданнях.

## Проєкти

### 🛠️ PULT+ — вебсистема сервісного центру
**Репозиторій:** [Servis-Sait](https://github.com/stas1212212/Servis-Sait)

Практичний проєкт вебсистеми для сервісного центру. У межах роботи над ним займався формулюванням вимог, налаштуванням середовища, перевіркою функцій і пошуком технічних проблем. Проєкт включає роботу з Node.js, PostgreSQL, авторизацією та функціями адміністрування.

**Мій внесок:** постановка завдань, інтеграція й перевірка змін, діагностика помилок, робота з GitHub. Значна частина програмного коду створювалася за допомогою ШІ; не позиціоную цей проєкт як повністю самостійну розробку.

### 🎮 The Hillbilly's Revenge — ігровий проєкт на Godot 4
**Репозиторій:** [The-Hillbilly-s-Revenge](https://github.com/stas1212212/The-Hillbilly-s-Revenge)

Практика роботи з GitHub, структурою ігрового проєкту, налаштуванням ресурсів і тестуванням змін у Godot 4. Цей проєкт демонструє досвід роботи з інструментами розробки та організації файлів, а не спеціалізацію на кібербезпеці.

## Навчальна підготовка з інформаційної безпеки

- Моделі та механізми контролю доступу: ACL, DAC, MAC, RBAC, принцип найменших привілеїв.
- Безпека Windows: права доступу, системні служби, журнали подій та типові помилки конфігурації.
- Основи мережевої безпеки, захисту IoT-пристроїв і оцінювання ризиків.
- Ознайомлення з документацією й стандартами інформаційної безпеки.

## Що розвиваю далі

- Практичний аналіз журналів Windows і Linux.
- Основи SOC: triage сповіщень, класифікація інцидентів, документування висновків.
- Практика з Wireshark та навчальною SIEM-лабораторією.
- Технічна англійська для читання документації та роботи з інцидентами.
